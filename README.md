# Ebenezer Lubis Portfolio

A personal portfolio built with Next.js, React, TypeScript, CSS Modules, and `next/image`.

The site presents selected projects as case files instead of generic cards, with a full-screen hero, project detail carousel, capability sections, contact modal, and responsive navigation.

## Tech Stack

- Next.js App Router
- React
- TypeScript
- CSS Modules
- React Icons
- Optimized local images with `next/image`

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production Check

```bash
npm run lint
npm run build
```

For deployment, set `NEXT_PUBLIC_SITE_URL` to the final domain so social preview images resolve correctly.
